# PathAdvisor Conversation UX v1

PathAdvisor now behaves more like a real chat conversation. Messages scroll like a text thread, and you can jump back to the latest reply if you scroll up. The input stays pinned at the bottom so it is always ready to use.

We also added simple conversation controls: start a new thread, clear the current thread (with a confirmation), and export the current conversation. Exports copy a Markdown transcript to the clipboard and download a JSON file for reference.

A new Conversations screen in the left navigation lets you browse, rename, and delete past threads. Selecting a thread immediately updates PathAdvisor so you can continue where you left off. All history is stored locally on the device, and nothing is shared or synced externally.
