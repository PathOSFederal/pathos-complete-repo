# Desktop Job Seeker UX Contract v1

> Outline only. Short bullet points; no long prose.

---

## Core loop

- Profile → Target Job → Score → Uplift → Resume edits → Rescore → Export
- Target job is the pivot: selection drives readiness and guidance

---

## Page responsibilities

- **Dashboard / Saved Jobs:** Entry; recent activity; next best actions
- **Job Search (Explore):** Browse; set target job; compare listings
- **Resume & Career:** Target job context; readiness; resume edits; export
- **PathAdvisor (sidebar):** Context capsule; guidance; prompts; details; chat input

---

## PathAdvisor behavior rules

- Context capsule always visible: target job (or “None selected”), readiness, set-target action, one-line next instruction
- Primary guidance card always open: “What to do next,” 2–3 bullets, one primary CTA
- Suggested prompts and Details collapsed by default
- If no target job: capsule shows “None selected”; CTA drives to selecting a target job
- Chat: no long transcript by default; if messages exist, show only last 1–2 compact bubbles
- Expand/collapse, privacy indicator, and clear are header icons only (compact)

---

## Trust microcopy principles

- Calm, concise, non-alarming
- Local-first and private-by-default stated in header subtext
- Details section: How scoring works; what PathOS can’t control; data & privacy

---

## No outcome guarantees

- PathOS helps you prepare; it does not guarantee selection or hiring
- Final hiring decisions depend on agency review, veterans’ preference, and other factors outside resume analysis
